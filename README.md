# Telco Customer Churn Analysis

Exploratory data analysis of a telecom customer dataset to find which customer groups are most likely to churn (contract type, tenure, payment method, services and more). A PDF write-up of the findings is included.

**🔗 Run it live:** every notebook below opens directly in Google Colab, no setup needed.

- **Report (PDF):** [Teleco Customer Churn Analysys.pdf](https://github.com/amitmohanty022/Teleco-Customer-Churn-Analysis/blob/main/Teleco%20Customer%20Churn%20Analysys.pdf)
- **Dataset:** `Customer Churn.csv` (in this repo). When running in Colab, upload it to the session first.

## Tech stack

Python, pandas, NumPy, Matplotlib, Seaborn
